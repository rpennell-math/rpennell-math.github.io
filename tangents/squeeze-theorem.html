The Squeeze Theorem, ε–δ Style

If f is trapped between two functions that both head to L, then f has nowhere else to go.

Suppose g(x) ≤ f(x) ≤ h(x) for all x near a (except possibly at a), and limx→a g(x) = limx→a h(x) = L. Then limx→a f(x) = L.
g (lower) f (squeezed) h (upper) ε-band δ-band the "trap" between g and h

Drag left/right on the graph to change δ, up/down to change ε. Inside the δ-band, any part of a curve that leaves the ε-band turns red.

The proof, as a picture

  1. Someone hands you an ε > 0 (the blue band).
  2. Since g → L, there is a δg with L − ε < g(x) < L + ε whenever 0 < |x − a| < δg. Press “δ for g”: g is all green.
  3. Since h → L, there is a δh doing the same for h. Press “δ for h”.
  4. Let δ = min(δg, δh). Inside that band both g and h are in the ε-band, so
       L − ε < g(x) ≤ f(x) ≤ h(x) < L + ε.
  5. So |f(x) − L| < ε: f is green too — and we never had to know anything about f except that it’s trapped. That’s the whole theorem.

Things to try: press “δ for g” alone on the first example and notice h (and f) can still escape. Then use the min. Or hit “Squeeze it” and watch the bands shrink while f stays caught.
