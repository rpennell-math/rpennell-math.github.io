The ε–δ Definition of a Limit

Choose a tolerance ε around the limit, then find a δ that keeps the function inside it.

We say limx→a f(x) = L if for every ε > 0 there exists a δ > 0 such that  0 < |x − a| < δ  ⟹  |f(x) − L| < ε.

How to read the picture

  1. Your opponent picks ε: “I want f(x) within ε of L.” That is the horizontal blue band.
  2. You answer with δ: “Then stay within δ of a.” That is the vertical orange band.
  3. You win this round if every point of the graph in the orange band (except possibly at x = a itself) is also in the blue band — the curve there is entirely green.
  4. The limit is L exactly when you can win every round, no matter how small ε gets. Usually smaller ε forces smaller δ.
  5. The value f(a) is ignored (that is the “0 <” in 0 < |x − a|), so holes and misplaced points don’t matter.
